06Ler e validar

function cadastrar(evento) {
  evento.preventDefault(); // não recarrega

  const nome  = document.getElementById("nome").value;
  const cargo = document.getElementById("cargo").value;
  const email = document.getElementById("email").value;

  const erro = document.getElementById("erro");

  if (!nome || !cargo || !email) {
    erro.textContent = "Preencha tudo.";
    return;
  }
  • .value
    o texto digitado
  • preventDefault
    evita recarregar a página
  • if + return
    vazio? mostra o erro e para
validaçãoFaça a leitura dos três campos e a checagem de vazio. Se algum estiver em branco, mostre a mensagem em #erro e interrompa.
valide também o campo novoLeia o campo que você adicionou e inclua-o na checagem de obrigatório, com sua própria mensagem de erro.
app.js · criar o item

07Criar o item da lista

  // cria o <li>
  const item = document.createElement("li");
  item.textContent = `${nome} — ${cargo} (${email})`;

  // insere na lista
  document.getElementById("lista")
          .appendChild(item);
}
  • createElement
    fabrica o <li>
  • textContent
    escreve o texto do item
  • appendChild
    insere — só aqui aparece na tela
inserir na listaCrie o <li> com os dados do funcionário e insira na #lista. Cadastre alguns e veja os itens nascerem.
mostre o campo novoInclua o dado que você adicionou no texto do <li>, para que ele apareça junto no item da lista.
app.js · remover

08Botão de remover

  // botão dentro do item
  const btn = document.createElement("button");
  btn.textContent = "remover";
  btn.onclick = function() {
    item.remove(); // tira da tela
  };

  item.appendChild(btn);
  • button
    um botão por item
  • onclick
    o que fazer ao clicar
  • item.remove()
    apaga aquele item da lista
removerAdicione um botão remover a cada item, que apague só aquele funcionário ao ser clicado.
limpe o formulárioDepois de inserir na lista, faça o formulário voltar a ficar vazio para o próximo cadastro (dica: form.reset()).
